# Дополнительные подписи интерфейса

`LauncherLabels.java` содержит перевод динамических надписей и русские подписи кнопок, которые в штатном лаунчере нарисованы внутри картинок. Он вызывается из изменённых обработчиков лаунчера. Идентификаторы элементов относятся к проверенной версии 2.4.2.

`RecentHints.java` показывает русские подписи поверх штатного окна последних приложений. Окна не получают фокус и не принимают нажатия. Управление задачами остаётся у штатной SystemUI. Модуль вызывается службой боковой панели.

Эти файлы не являются самостоятельными приложениями. Готовые подписанные APK лежат в релизе, их размеры и SHA-256 закреплены в манифесте. Для компиляции модулей использованы Java 17, Android SDK 34 и D8 с минимальным API 23. Ключ подписи в репозиторий не входит.
