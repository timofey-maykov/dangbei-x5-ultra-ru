# Патч YouTube Fix

Локальная адаптация для Dangbei X5 Ultra, Android 11, сборка 3764. Готовый APK ставится из меню установщика, этот раздел нужен только для работы с исходниками.

За основу взят YouTube TV 7.32.300, код 732300320, armeabi-v7a. SHA-256 исходного APK: `f450a094f1f7e8b8b7b8d707a2238b919542d2a925c484e6fbcf09ccf32b7a61`. До изменения подпись была сверена с установленным YouTube Google, SHA-256 сертификата `21199d112cece428c82cb0df221da24ff8674c7a982a83a17a970eec43305b4a`.

Патч отключает обращения к DRM, которые зависают из-за отсутствующей библиотеки PlayReady, меняет пакет на `local.ru.youtube.tv` и подключает локальный JS-фильтр к Cobalt. Фильтр убирает рекламные расписания и рекламные карточки из ответов YouTube, внешние скрипты он не загружает. Обычные видео сохраняются, DRM-видео не поддерживаются, Premium не подменяется.

GoogleProcessGuard восстанавливает штатные исключения DAST для Google после загрузки проектора и обновления APK. Он также вызывается установщиком перед первым запуском, поэтому YouTube Fix можно ставить отдельно от русского лаунчера. Для доступа к API Dangbei установщик сохраняет прежнее значение hidden_api_policy и выставляет 1, при восстановлении возвращает прежнее значение.

На этой прошивке BOOT_COMPLETED доставляется только встроенному списку приложений, поэтому для раннего восстановления исключений используется LOCKED_BOOT_COMPLETED. Обработчик не читает аккаунты или данные пользователя, сохранённые исключения меняет только установщик после бэкапа.

Способ подключения к WebContents взят из [FaroTV](https://github.com/jair1c/farotv-patches/tree/8478a5a4dfbe6b315fce31d76d5c40986bbae5d6) и [ysamjo/morphe-patches](https://github.com/ysamjo/morphe-patches/tree/74c4272edb6b82219926d7f6e75ef4347c06663d), локальные исходники патча опубликованы под GPL-3.0, текст лицензии рядом. Это не лицензия на само приложение YouTube.

## Сборка

Нужны Java 17, Android SDK с android-34 и build-tools 34.0.0, Apktool 3.0.3, Python 3.10 или новее. Исходный APK нужно получить отдельно, скрипт проверит его SHA-256 до распаковки. Рабочая папка должна быть новой.

```sh
python3 scripts/build_youtube_fix.py \
  --original /path/to/YouTube-7.32.300-original.apk \
  --sdk /path/to/android-sdk \
  --apktool /path/to/apktool.jar \
  --output build/YouTube-Fix-unsigned.apk
node patches/youtube-fix/test-filter.cjs
```

На выходе APK без подписи, его нужно подписать своим ключом через apksigner. Своим ключом нельзя обновить уже установленную сборку из этого репозитория, Android потребует одинаковую подпись. Ключ релиза не публикуется.

В исходном приложении три DEX-файла, код расширения добавляется четвёртым, исходный classes3.dex сохраняется. Проверка фильтра проверяет удаление рекламы, сохранение видеоссылок, обработку ошибок JSON, reviver, повторное подключение и ограничение домена.
