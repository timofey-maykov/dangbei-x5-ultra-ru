# Русификация X5 Ultra 1.2.1

Убрал надпись Удерживайте OK с плиток приложений в Кемпинге. На плитке остались значок и название. Долгое нажатие OK по-прежнему открывает меню плитки.

Для обновления скачайте архив для своего компьютера, распакуйте целиком и снова выберите русификацию. Установщик сначала сделает и проверит бэкап. Приложения, папки и расположение плиток сохранятся.

Python, ADB и APK уже в архиве. На Windows откройте start.bat, на Mac откройте start.command, на Linux запустите start.sh. Под Mac с Intel и Apple Silicon разные архивы. Source code для установки не нужен.

Проверял на DBX5 Ultra, модель X5U6128, Android 11, сборка 3764. Состав остальных приложений не изменился.
