# Русификация X5 Ultra 1.1.0

Теперь для установки достаточно распаковать архив и открыть файл запуска. Python, ADB и APK уже внутри. В меню можно выбрать русификацию, Google Play или всё вместе. Перед любыми изменениями установщик делает и проверяет бэкап.

В этой версии:

- Добавлена русская «Трансляция». Изображение и звук с телефона проверены.
- Исправлен источник при включении. Выбор сохраняется и после перезагрузки.
- Дополнен перевод четырёх режимов лаунчера, кнопок и подсказок. Ширина вкладок рассчитана по русскому тексту.
- Добавлены русские подписи в окне последних приложений, которое открывается двойным нажатием «Домой».
- Исправлено повторное подключение службы боковой кнопки после обновления.

Выберите архив своей системы:

| Система | Архив | Запуск |
| --- | --- | --- |
| Windows 10/11 x64 | `dangbei-x5-ultra-ru-1.1.0-windows-x64.zip` | `start.bat` |
| macOS 15+, Apple Silicon | `dangbei-x5-ultra-ru-1.1.0-macos-arm64.zip` | `start.command` |
| macOS 15+, Intel | `dangbei-x5-ultra-ru-1.1.0-macos-x64.zip` | `start.command` |
| Linux x64, Ubuntu 22.04+ | `dangbei-x5-ultra-ru-1.1.0-linux-x64.zip` | `start.sh` |

Распакуйте архив целиком. Отдельные APK и архивы Source code нужны для ручной работы; для обычной установки выбирайте ZIP с названием своей ОС.

Проверено на DBX5 Ultra / X5U6128, Android 11, сборка 3764. На другой прошивке установщик остановится. Китайский онлайн-каталог, афиши, реклама и часть иллюстраций «Трансляции» остаются в оригинале. Google Ассистента в комплекте нет; установка Google Play не добавляет сертификацию и DRM.
