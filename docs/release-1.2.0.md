# Русификация X5 Ultra 1.2.0

В Кемпинге можно настроить рабочий стол под себя: добавить приложения, убрать ненужные плитки, собрать папки и выбрать расположение.

- Откройте Добавить приложение, выберите приложение и нажмите OK.
- Чтобы убрать плитку, выделите её, нажмите Меню или удерживайте OK и выберите Убрать плитку. Приложение останется установленным.
- Штатные плитки возвращаются через Меню, затем Скрытые плитки.
- Вид и расположение: ряд или сетка в два/три ряда, размер плиток, расстояния, отступы и положение блока.
- Переместить: стрелки меняют место плитки, OK или Назад сохраняет порядок.
- Сортировка: по названию, приложения или папки сначала, ручной порядок.
- Создать папку: выберите название и отметьте приложения. Папку можно переименовать. При её удалении приложения возвращаются на рабочий стол.

Нижний раздел Оформление работает и с сеткой. Метка выбранного фона переведена. Выбор сохраняется после перезапуска лаунчера. Кнопка добавления остаётся доступной, даже если убрать все остальные плитки.

Для обновления распакуйте комплект своей ОС и снова выберите русификацию. Установщик сначала создаст и проверит бэкап. Остальные APK не изменились по сравнению с 1.1.0.

В архивах уже есть Python, ADB и APK. На Windows x64 откройте `start.bat`, на macOS Intel/Apple Silicon откройте `start.command`, на Linux x64 запустите `start.sh`. Скачивайте архив с названием своей ОС, не Source code.

Проверенная прошивка: DBX5 Ultra / X5U6128, Android 11, сборка 3764. Ограничения Google и китайского онлайн-каталога остались прежними.
