# Русификация X5 Ultra 1.3.0

Добавил YouTube Fix на базе YouTube TV 7.32.300, он запускается на прошивке с неработающим PlayReady и убирает рекламу из ответов плеера. В меню установщика появился пункт 8, YouTube Fix и Google, в вариант Всё сразу он тоже включён. При выборе пункта 8 лаунчер и клавиатура не меняются.

Исправил вылет YouTube при очистке памяти Dangbei, защита сервисов Google восстанавливается после перезагрузки. Обычные ролики и вход в аккаунт проверены, платные фильмы с DRM этим не чинятся, рекламные вставки внутри самих роликов остаются.

В Кемпинге баннеры приложений теперь занимают всю плитку, если баннера нет, показывается крупный значок. Долгое нажатие OK по-прежнему открывает настройки плитки.

Перед установкой сохраняется и проверяется бэкап, теперь в нём есть состояние штатного YouTube и исключения очистки памяти для Google. Более новые версии Google на проекторе сохраняются.

Скачайте архив для своего компьютера и распакуйте целиком, Python, ADB и APK уже внутри. На Windows откройте start.bat, на Mac start.command, на Linux start.sh. Проверено на DBX5 Ultra, X5U6128, Android 11, сборка 3764, второй чистый проектор не проверялся.
