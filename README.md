# Русификация Dangbei X5 Ultra

Собрал русификацию для своего Dangbei X5 Ultra. Здесь русский лаунчер, настройки, боковая панель пульта и «Мастер изображения». Поправил подписи, подсказки и цвета меню, чтобы всё читалось с нормальным размером шрифта.

В установщике есть меню. Можно поставить только русский интерфейс, только Google или всё сразу. Перед установкой он делает бэкап на компьютере и проверяет сохранённые файлы. Если бэкап не получился, установка не начнётся.

## Для какого проектора

Проверено на DBX5 Ultra, модель X5U6128, Android 11, сборка 3764. Скрипт сверяет модель и версии штатных приложений. На другой прошивке он остановится. Это специально: настройки изображения завязаны на службы конкретной прошивки.

Это установка приложений через ADB. Root и перепрошивка не нужны. Штатные приложения остаются на месте; старые лаунчеры отключаются после проверки нового главного экрана.

## Что скачать

Откройте [релизы](https://github.com/timofey-maykov/dangbei-x5-ultra-ru/releases/latest) и скачайте `dangbei-x5-ultra-ru-1.0.0.zip`. В нём установщик и все нужные APK. Архивы `Source code` содержат только код, без APK.

На компьютере нужны:

- [Python 3.10 или новее](https://www.python.org/downloads/). На Windows при установке отметьте `Add python.exe to PATH`.
- [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools). Это набор, в котором лежит `adb`. Можно распаковать папку `platform-tools` рядом с `install.py`.
- Около 2 ГБ свободного места под архив и бэкапы.

Распакуйте архив целиком. Папка `apks` должна остаться рядом с `install.py`.

## Подключение

Подключите компьютер и проектор к одной сети. В настройках проектора включите отладку ADB/USB и посмотрите его IP-адрес. Названия этих пунктов зависят от прошивки; на китайском ищите `USB调试` или `ADB调试`.

Для подключения по сети обычно нужен адрес вида `192.168.1.100:5555`. Это пример, подставьте свой адрес. Если на экране появится запрос на отладку с этого компьютера, разрешите подключение.

Сам скрипт отладку не включает. Если соединение не устанавливается, сначала проверьте его вручную:

```sh
adb connect 192.168.1.100:5555
adb devices
```

Рядом с адресом должно быть `device`. При `unauthorized` нужно подтвердить запрос на проекторе. Если подключаетесь через USB, используйте серийный номер из `adb devices` вместо IP.

## Установка через меню

На Windows запустите `start.bat`. На macOS или Linux откройте терминал в распакованной папке:

```sh
bash start.sh
```

В меню будут варианты:

1. Русификация и клавиатура.
2. Только сервисы Google и Play Маркет.
3. Всё сразу: русификация, клавиатура и Google.
4. Только бэкап, ничего не менять.
5. Восстановить из бэкапа.
6. Проверить совместимость.
7. Скачать файлы релиза, если скачали только исходники.
0. Выход.

Выберите нужный номер и введите адрес проектора. Дождитесь сообщения «Готово». Во время копирования APK может несколько минут не быть нового вывода. Не закрывайте окно и не выключайте проектор.

После установки перезагрузите проектор обычным способом. Проверьте главный экран, настройки и боковую кнопку пульта.

## Клавиатура

Вместо китайской Sogou используется [LeanKeyboard](https://github.com/yuliskov/LeanKeyboard). Sogou и Google Voice отключаются только как способы ввода. Их приложения не удаляются. Так обычное поле ввода не переключится на голосовую клавиатуру. Это не настройка аппаратного микрофона пульта.

В настройках LeanKeyboard выберите русский и английский языки. Раскладка переключается кнопкой с глобусом; также можно удерживать пробел. Для кодов профиля нужны английские буквы и цифры. Поле «Добавить по коду» больше не притворяется адресом электронной почты.

Если хотите оставить свою клавиатуру, используйте команду `install --no-keyboard` из раздела ниже.

## Google

Пункт 2 устанавливает Google Services Framework, Google Play Services и Play Маркет. Лаунчер и язык интерфейса при этом не меняются. Пункт 3 ставит их вместе с русификацией.

После перезагрузки откройте Google Play и войдите в свой аккаунт. Пароль вводится на проекторе. Скрипт не копирует аккаунты, токены или данные приложений с другого устройства.

На моём проекторе вход в аккаунт, каталог магазина и установка приложения работали. Установка этих APK не добавляет сертификацию Google или отсутствующие DRM-библиотеки. Официальный YouTube на проверенной прошивке зависал при запуске из-за PlayReady; для просмотра я использую SmartTube. В этот архив он не входит.

## Что находится в бэкапе

Для каждого запуска создаётся новая папка внутри `backups`. Скрипт сохраняет APK затрагиваемых приложений, включая все части split APK, их состояние, текущий главный экран, способ ввода, изменяемые настройки и подписи боковой панели. Контрольные суммы сверяются с файлами на проекторе.

Это не полный образ проектора. Без root здесь нет копии закрытых данных приложений, аккаунтов, Wi-Fi-паролей и разделов прошивки. При восстановлении возвращаются сохранённые APK и настройки. Если приложение появилось только во время установки, оно удаляется вместе с его данными. Уже существовавшие приложения переустанавливаются поверх, без очистки данных.

Не удаляйте свою папку `backups`. Не выкладывайте её в GitHub: в ней есть сведения о вашем устройстве. Бэкап привязан к серийному номеру и прошивке, на другом проекторе восстановление не запустится.

## Как вернуть обратно

Запустите установщик, выберите пункт 5 и нужный бэкап. Скрипт сначала проверит устройство и все сохранённые APK. После восстановления перезагрузите проектор.

Если установка оборвалась, сохраните путь к бэкапу из окна. При потере сети сначала восстановите ADB-подключение, затем запустите восстановление. Скрипт не удаляет существующее приложение ради обхода ошибки подписи или запрета понижения версии.

## Команды без меню

На Windows вместо `python3` можно писать `py -3`.

```sh
# Только проверка, без изменений
python3 install.py --device 192.168.1.100:5555 check

# Русификация и LeanKeyboard; бэкап сделается сам
python3 install.py --device 192.168.1.100:5555 install

# Русификация вместе с Google
python3 install.py --device 192.168.1.100:5555 install --google

# Только Google
python3 install.py --device 192.168.1.100:5555 install-google

# Оставить свою клавиатуру
python3 install.py --device 192.168.1.100:5555 install --no-keyboard

# Отдельно сохранить бэкап, включая Google
python3 install.py --device 192.168.1.100:5555 backup --google

# Восстановить конкретную копию
python3 install.py --device 192.168.1.100:5555 restore backups/ИМЯ-ПАПКИ
```

Если `adb` не найден, укажите полный путь через `--adb`. Этот параметр, как и `--device`, пишется перед командой:

```sh
python3 install.py --adb ./platform-tools/adb --device 192.168.1.100:5555 check
```

## Что ещё осталось на китайском

Онлайн-баннеры, реклама и содержимое сторонних приложений. Перевод относится к лаунчеру, настройкам, боковой панели и «Мастеру изображения», а не ко всем приложениям на проекторе. Голосовой помощник Dangbei русскую речь от этой установки понимать не начнёт.

Подробности проверки лежат в [docs/testing.md](docs/testing.md). Состав релиза и SHA-256 файлов записаны в [manifest.json](manifest.json).
